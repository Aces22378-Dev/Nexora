THE PROJECT

Small beginnings.
Big possibilities.

Nexora is an independent gaming platform project built around a simple idea: make it easy to discover and launch games from one place.

The project is currently in Alpha. Features and the game library may change as development continues. Nexis and other future features are not yet available.
